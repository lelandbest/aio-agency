# Walkthrough - Branding Audit + Letterhead System

## Overview
Implemented a centralized branding system and letterhead template for Cortex reports. Branding is now tenant-aware, persistent, and used across the application.

---

## What Changed

### 1. Branding Audit

**Found:**
- Settings has basic branding tab (theme, colors, layout)
- WhiteLabelSettings.jsx exists but is a stub
- Multiple hardcoded "AIO CRM" references in:
  - Sidebar.jsx
  - TopBar.jsx
  - App.jsx
  - Settings/index.jsx

**Missing:**
- No logo upload/display
- No branding persistence
- No brand config object
- No report letterhead
- No footer/disclaimer fields

---

### 2. BrandContext (`frontend/src/contexts/BrandContext.jsx`)

New centralized brand context with:

```javascript
DEFAULT_BRAND_CONFIG = {
  brandName: 'AIO CRM',
  logoUrl: '/aio-button-192px.png',
  primaryColor: '#3b82f6',
  secondaryColor: '#1e40af',
  accentColor: '#8b5cf6',
  footerText: 'Generated by Cortex',
  disclaimer: 'Confidential - Internal Use Only',
  contactInfo: '',
  reportHeaderLabel: 'Cortex Intelligence Report'
}
```

**Features:**
- LocalStorage persistence
- React Context provider
- `useBrand()` hook for components
- `getBrandConfig()` helper function

---

### 3. ReportLetterheadTemplate (`frontend/src/templates/ReportLetterheadTemplate.jsx`)

New letterhead component for branded reports:

**Structure:**
1. Header (logo, brand name, report title, type, date)
2. Divider with primary color
3. Report body (sanitized content)
4. Footer (footer text, disclaimer, contact, generator credit)

**Props:**
```javascript
{
  brandConfig,    // Brand configuration object
  reportMeta,     // { title, type, generatedAt, accountName }
  reportBody,     // AI-generated content
  isFallback      // Show fallback badge
}
```

---

### 4. Settings Extension (`modules/Settings/index.jsx`)

Added "Report Branding" section with editable fields:

| Field | Description |
|-------|-------------|
| Brand Name | Display name for reports |
| Logo URL | Path to logo image |
| Primary Color | Brand color for header/accent |
| Report Header Label | Title shown on reports |
| Footer Text | Custom footer message |
| Disclaimer | Confidentiality notice |
| Contact Info | Email or contact details |

Changes persist to localStorage and sync with BrandContext.

---

### 5. Component Updates

**Sidebar.jsx:**
- Now uses `useBrand()` hook
- Reads brandName and logoUrl from config
- Falls back to defaults gracefully

**TopBar.jsx:**
- Uses brandConfig for tenant fallback
- Consistent branding across UI

**App.jsx:**
- Wrapped with `<BrandProvider>`

**Brain/index.jsx:**
- Saves reportMeta and brandConfig with each report
- Reports include branding metadata for future display

## Branding Flow

```
Settings (Branding Tab)
  ↓ (save to localStorage)
BrandContext
  ↓ (useBrand hook)
Sidebar / TopBar / Brain
  ↓ (save with report)
Report Metadata (in brain items)
  ↓ (future: render with)
ReportLetterheadTemplate
```

## Usage

### Using Brand Config in Components

```javascript
import { useBrand } from '../contexts/BrandContext';

const MyComponent = () => {
  const { brandConfig } = useBrand();
  return <div>{brandConfig.brandName}</div>;
};
```

### Using Letterhead Template

```javascript
import { ReportLetterheadTemplate } from '../templates';

<ReportLetterheadTemplate
  brandConfig={brandConfig}
  reportMeta={{
    reportTitle: 'Revenue Intelligence',
    reportType: 'Quarterly',
    generatedAt: new Date().toISOString(),
    accountName: 'Acme Corp'
  }}
  reportBody={aiGeneratedContent}
  isFallback={false}
/>
```
