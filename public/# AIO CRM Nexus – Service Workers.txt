# AIO CRM Nexus – Service Worker / PWA Architecture Review

You are performing a repository-aware architecture review. Do **not** make assumptions or apply changes until you have verified them from the codebase.

## Objective

Determine whether our implementation of Service Workers and the Vite PWA plugin is architecturally correct for this project, whether Service Workers should exist during development at all, and whether our current implementation is causing unnecessary complexity or stale state.

This is **not** simply a bug fix.

I want an architectural recommendation based on the actual repository.

---

## Project Context

This project is AIO CRM Nexus.

Characteristics:

* Vite frontend
* React
* FastAPI backend
* Local desktop development
* Frequent branch switching
* Constant hot reload
* Rapid UI iteration
* Authentication
* API-heavy application
* ReactFlow interfaces
* Future Tauri packaging
* Multi-agent execution platform

Because of the development style, stale browser caches or stale service workers are a significant concern.
