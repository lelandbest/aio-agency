Studio Manual

1. Operational Overview

The AIO Studio is a high-precision transformation appliance. It is engineered to ingested raw multimodal data and refine it into structured system artifacts through a sequence of tactical transformations.

2. The Control Deck

The Nexus Hub

The primary point of entry. Use FILE for local assets, WEB for URL ingestion, or MCP for protocol-direct links. The Nexus Drop Zone is a 1.25x-scaled target for all multimodal bridging.

Matrix Action Pads

A tactile grid for accelerated generation. Selecting a pad pins a specific tactical form for mission configuration.

Primary Action Button

The floating centered anchor at the island's base. This button is fixed to the appliance boundary and remains stable regardless of internal content expansion.

3. Monitoring Stations

Monitor A // Program

Displays the active asset on the GLOBAL_BUS. Uses a high-contrast aspect-video viewport for precise media review.

Monitor B // Review

The textual hub. Contains the TXT Readout for script evaluation, the Job Queue for background processing, and the Vault for asset management.

4. Essential Workflows

  • Ingestion: Drag an asset to the Nexus Tower.
  • Configuration: Select an Action, fill the Tactical Form.
  • Execution: Execute via the Floating Anchor button.
  • Ingestion: Push completed artifacts from the Vault to the Brain.
