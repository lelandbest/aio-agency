1. Ingress & Egress Architecture

AIO Nexus v2 operates as an autonomous local appliance. External landing pages (e.g. goaio.us) deliver submissions via a secure public tunnel directly into the local SQLite store, triggering internal flows and outbound webhooks to Make.com or n8n.

[PUBLIC INTERNET]                 [SECURE INGRESS]            [LOCAL AIO NEXUS APPLIANCE (:8001)]
Landing Page / Website           Tailscale Funnel / ngrok     FastAPI Single-Port Server
┌──────────────────────┐         ┌────────────────┐          ┌────────────────────────────────┐
│ HTML5 / React Form   │         │ Public HTTPS   │          │ Ingress Boundary               │
│ - Contact Inquiries  │──POST──▶│ :443 -> :8001  │─────────▶│ POST /api/forms/by-slug/{slug} │
│ - Podcast Intake     │         │ (TLS Ingress)  │          │ - Contact Dedup & Creation     │
└──────────────────────┘         └────────────────┘          └───────────────┬────────────────┘
                                                                             │
                                                                             ▼
[EXTERNAL AUTOMATIONS]           [OUTBOUND ADAPTERS]         ┌────────────────────────────────┐

┌──────────────────────┐         ┌────────────────┐          │ - Trigger: form_submitted      │

2. Ingress Setup: Exposing Your Local Appliance

Option A: Tailscale Funnel (Recommended)

100% Free, permanent public HTTPS endpoint with automatic TLS certificates.

tailscale funnel 8001

Runs in background:

tailscale funnel --bg 8001

Public URL: https://<node>.<tailnet>.ts.net/

Option B: ngrok (Instant Demos)

Instant zero-config public forwarding URL for rapid live testing.

ngrok http 8001

Public URL: https://<subdomain>.ngrok-free.app/

3. Public Submission API Reference

Endpoint Method Auth Description
/api/forms/by-slug/{slug}/submit POST Public Primary submission endpoint using human-readable slug
/api/forms/{formId}/submit POST Public Alternative submission endpoint using internal Form ID
/api/forms/by-slug/{slug} GET Public Retrieve dynamic form schema, fields & styling
/api/health GET Public Heartbeat monitor for tunnels & uptime checkers

Request Payload Schema (JSON)

{
  "formData": {
    "first_name": "Leland",
    "last_name": "Best",
    "email": "leland@goaio.us",
    "phone": "+1-555-0199",
    "company": "AIO Agency",
    "message": "Inquiry regarding podcast operations automation."
  }
}

Success Response (200 OK)

{
  "success": true,
  "contactId": "contact-0f9f5cf45d",
  "created": true,
  "submissionId": "submission-15d89012e3"
}

4. Universal Website Embed Code (HTML + JavaScript)

Copy and paste this snippet directly into Webflow, WordPress, Squarespace, or any static HTML site:

<!-- AIO Nexus Smart Intake Form -->
<form id="aio-intake-form" style="max-width: 480px; margin: 0 auto; display: flex; flex-direction: column; gap: 12px;">
  <input type="text" id="first_name" placeholder="First Name *" required style="padding: 10px; border-radius: 6px; border: 1px solid #ccc;" />
  <input type="email" id="email" placeholder="Email Address *" required style="padding: 10px; border-radius: 6px; border: 1px solid #ccc;" />
  <input type="tel" id="phone" placeholder="Phone Number" style="padding: 10px; border-radius: 6px; border: 1px solid #ccc;" />
  <textarea id="message" rows="4" placeholder="How can we help?" style="padding: 10px; border-radius: 6px; border: 1px solid #ccc;"></textarea>
  <button type="submit" id="aio-btn" style="background: #2563eb; color: #fff; padding: 12px; border: none; border-radius: 6px; font-weight: 600; cursor: pointer;">Submit Inquiry</button>
  <div id="aio-status" style="display: none; padding: 10px; border-radius: 6px; font-size: 14px; text-align: center;"></div>
</form>

<script>
document.getElementById("aio-intake-form").addEventListener("submit", async function(e) {
  e.preventDefault();
  const btn = document.getElementById("aio-btn");
  const status = document.getElementById("aio-status");
  btn.disabled = true; btn.innerText = "Submitting...";

  // REPLACE WITH YOUR TAILSCALE FUNNEL OR NGROK DOMAIN:
  const APPLIANCE_URL = "https://my-studio-node.tailnet-xyz.ts.net";
  const FORM_SLUG = "contact-us";

  try {
    const res = await fetch(`${APPLIANCE_URL}/api/forms/by-slug/${FORM_SLUG}/submit`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        formData: {
          first_name: document.getElementById("first_name").value,
          email: document.getElementById("email").value,
          phone: document.getElementById("phone").value,
          message: document.getElementById("message").value
        }
      })
    });
    const data = await res.json();
    if (res.ok && data.success) {
      status.style.display = "block";
      status.style.background = "#dcfce7";
      status.style.color = "#166534";
      status.innerText = "Thank you! Your submission has been received.";
      this.reset();
    } else {
      throw new Error(data.detail || "Submission failed.");
    }
  } catch (err) {
    status.style.display = "block";
    status.style.background = "#fee2e2";
    status.style.color = "#991b1b";
    status.innerText = err.message;
  } finally {
    btn.disabled = false; btn.innerText = "Submit Inquiry";
  }
});
</script>

5. Make.com & n8n Integration (Outputs)

Method 1: Direct Form Webhook (Zero Flow Setup)

In AIO Nexus, open CRM → Forms → Edit Form → Click Settings.

Paste your Make.com or n8n webhook URL into the Webhook URL field.

Every submission is immediately dispatched with this complete payload:

{
  "event": "form_submission",
  "formId": "form-6fa46f3f1c",
  "formName": "Podcast Guest Intake",
  "formSlug": "podcast-guest-intake",
  "submissionId": "submission-15d89012e3",
  "contactId": "contact-0f9f5cf45d",
  "formData": {
    "first_name": "Leland",
    "email": "leland@goaio.us",
    "message": "Automating podcast operations."
  },
  "submittedAt": "2026-09-06T22:16:24Z"
}

Method 2: Multi-Step Flow HTTP Request Node (Advanced)

Open Flows → Add a Trigger node with event form_submitted.

Add an http_request node to send enriched variables:

  • Method: POST
  • URL: https://hook.eu2.make.com/...
  • Body: {"email": "{{form_data.email}}", "contactId": "{{contact_id}}"}

6. Standalone Appliance Desktop Quick-Start

To run AIO Nexus v2 outside development mode on your Windows desktop:

  1. Run install-nexus.bat once to configure your environment and create the Desktop shortcut.
  2. Double-click "AIO Nexus Appliance" on your Desktop (or run run-appliance.bat).
  3. The single-port server will launch at http://localhost:8001 and automatically open your default browser.
  4. To stop the appliance, close the terminal window or run stop-appliance.bat.
